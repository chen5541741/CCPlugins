# Writeup 分析工具

## 你的角色

你需要帮助用户分析Vulhub、HackTheBox或其他CTF靶场的writeup，并生成详细的中文总结报告。

## 输入参数

- **source**: `{{source}}` - Writeup来源（网址或文件路径）
- **challenge_name**: `{{challenge_name}}` - 靶场名称

## 执行步骤

复制这张清单并跟踪你的进度：
```
执行进度:
— [ ] 步骤1：检查提供的信息
- [ ] 步骤2：writeup检查
- [ ] 步骤3：分析和检测
- [ ] 步骤4：生成中文报告
- [ ] 步骤5：保存文件
```

### 步骤1：检查提供的信息

首先检查当前是否已取得了靶场名称：
**如果没有取得**:
- 提示用户并结束流程
**如果有取得**:
- 继续检查当前提供的Writeup信息是什么类型：
  **如果source是URL**:
  - 执行进度清单中添加`步骤2.1：读取网页内容`
  **如果source是文件路径**:
  - 执行进度清单中添加`步骤2.2：读取文件内容`

### 步骤2.1：读取网页内容
尝试读取writeup内容：
- 使用WebFetch工具尝试读取网页内容
- 提示词应为："提取完整的writeup内容，包括所有攻击步骤、命令、代码片段和获得的信息"
**如果读取网页失败**：
- 执行进度清单中添加`步骤2.3：搜索相关writeup`
- 然后按照 [步骤2.3：搜索相关writeup](###步骤2.3：搜索相关writeup)继续执行

### 步骤2.2：读取文件内容
尝试读取writeup内容：
- 使用Read工具读取本地文件内容
**如果读取网页失败**：
- 执行进度清单中添加`步骤2.3：搜索相关writeup`
- 然后按照 [步骤2.3：搜索相关writeup](###步骤2.3：搜索相关writeup)继续执行

### 步骤2.3：搜索相关writeup
尝试搜索靶场的writeup信息：
- 使用WebSearch工具搜索相关writeup
- 搜索关键词应包括：靶场名称、"writeup"、"walkthrough"、"solution"、"exploit"
- 尝试多次搜索获取详细信息

### 步骤3：分析和检测

从获取的writeup中提取以下关键信息：

#### 必须包含的内容：

1. **靶场概述**
   - 难度
   - 平台
   - 创建者
   - 发布时间
   - 操作系统
   - 关键技术

2. **攻击过程详解**（分步骤）
   - 每个步骤应包括：
     - 步骤名称（侦察、漏洞发现、利用等）
     - 执行的命令
     - 获得的信息
     - 其他关键内容

3. **关键技术点总结**
   - 列出所有重要的技术点，说明，关键工具或命令行

4. **攻击流程图**
   - 使用文本或图表展示完整攻击链

4. **漏洞原理分析**
   - 解释漏洞的技术原理
   - 为什么exploit能够成功

8. **参考来源**
   - 列出所有参考的writeup链接

#### 不需要的内容：
- 任何修复建议
- 任何经验教训总结

### 步骤4：生成中文报告

将分析结果整理成结构化的Markdown文档，要求：

- **必须使用中文**编写所有内容
- 使用清晰的标题层级（# ## ###）
- 代码块使用正确的语言标记（bash、python、javascript等）
- 表格格式展示关键信息
- 适当使用emoji增强可读性（可选）

### 步骤5：保存文件

使用Write工具将报告保存为：
- 文件名格式：`HTB_{{challenge_name}}_Writeup.md`
- 保存位置：当前工作目录
- 编码：UTF-8

## 输出要求

生成的报告应该：
- 结构清晰，层次分明
- 技术细节准确完整
- 命令和代码可直接复制使用
- 中文表达准确流畅
- 包含完整的攻击复现步骤

## 示例执行流程

1. 尝试使用WebFetch读取 `{{source}}`
2. 如果返回403或其他错误，使用WebSearch搜索 "{{challenge_name}} writeup"
3. 分析获取的内容，提取关键攻击步骤
4. 整理成中文Markdown格式
5. 保存为 `HTB_{{challenge_name}}_Writeup.md`
6. 向用户确认文件已保存成功

## 注意事项

- 确保所有技术术语翻译准确
- 保留原始命令和代码（不翻译）
- 如果信息不完整，应使用WebSearch补充
- 标注信息来源的可靠性
- 包含免责声明（仅用于教育目的）
